# قارئ EPUB — أسطورة الإطار

قارئ EPUB عربي بتصميم هادئ، مبني باستخدام React وTypeScript وVite وEPUB.js. يحتوي المشروع على الكتاب المرفق مسبقًا، ولا يحتاج إلى رفع كتاب من داخل التطبيق.

## المتطلبات
- Node.js 18 أو أحدث (يفضّل إصدار LTS).
- npm.

## التشغيل محليًا
```bash
npm install
npm run dev
```
افتح رابط Vite الظاهر في الطرفية.

## إنشاء نسخة إنتاج
```bash
npm run build
npm run preview
```
ملفات الإنتاج ستظهر داخل `dist/`.

## الكتاب المضمّن
الكتاب موجود في:
`public/books/book.epub`

لاستبداله بكتاب آخر، ضع ملف EPUB الجديد في هذا المسار بنفس الاسم `book.epub` ثم أعد تشغيل التطبيق. لا توجد واجهة رفع داخل القارئ.

## الميزات الموجودة
- عرض محتوى EPUB الحقيقي والفهرس المستخرج منه عبر EPUB.js.
- التنقل السابق/التالي واختصارات الأسهم.
- وضع الصفحات ووضع التمرير المستمر.
- الثيم الداكن والفاتح والورقي.
- تعديل حجم الخط وارتفاع السطر وعرض القراءة.
- حفظ موضع القراءة والثيم والتفضيلات محليًا.
- حفظ علامات موضع القراءة، وتظليل النص المحدد، وإضافة ملاحظات شخصية.
- بحث نصي داخل ملفات الفصول المفهرسة من EPUB.
- ملء الشاشة واختصارات لوحة المفاتيح.
- واجهة RTL عربية متجاوبة.

## التخزين والخصوصية
تُحفظ التفضيلات والعلامات والملاحظات في `localStorage` على هذا المتصفح فقط. لا يوجد حساب أو مزامنة بين الأجهزة.

## ملاحظات تقنية
- EPUB.js يعمل على عرض الكتاب والتنقل بين فصوله. قد تختلف جودة دعم التظليل أو بعض عناصر EPUB حسب بنية الكتاب والمتصفح.
- بحث الكتاب يجمع نتائج النصوص من عناصر الـ spine؛ وقد لا يعيد بعض النتائج الموجودة داخل صور أو عناصر غير نصية.
- المشروع يستخدم Google Fonts لتحميل خط الواجهة عند توفر الإنترنت، مع بدائل محلية من النظام. يمكن حذف استيراد الخط من `src/styles.css` للاستخدام دون اتصال.
- عند نشر التطبيق، يجب أن تسمح الاستضافة بتقديم ملفات `.epub` كملفات static.
